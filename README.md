# Longsen Distiller · 全域蒸馏器

> 输入一个行业 / 品牌 / 网站 / 话题 → 输出一套全域认知系统。
> 从「信息」到「认知」到「决策」到「方案」的一站式蒸馏流水线。

## 这是什么

全域蒸馏器是一个结构化的情报蒸馏方法 + 可运行的前端演示：

- **输入**：任意行业 / 品牌 / 网站 / 话题（一句话即可）
- **输出**：一套全域认知系统（品牌全景 / 竞品拆解 / 痛点 / 机会 / 内容账号 / 关键词 / 风险 / 知识卡）+ 决策诊断 + 执行方案

核心是**四步流水线**：

```
蒸馏（建立认知系统）→ 诊断（值不值得做）→ 转化（怎么做）→ 交付（可执行产物）
```

## 能力矩阵

| 能力 | 说明 |
|:---|:---|
| 4 模式自动判定 | industry（行业）/ brand（品牌）/ website（网站）/ topic（话题） |
| 6 行业骨架匹配 | 自动匹配最合适的行业模板（DTC 电商 / AI 工具 / SaaS / 创作者经济等） |
| 7 步执行流水线 | 判定 → 骨架 → 建骨架 → 采集 → 结构化 → 蒸馏 → 交付 |
| URL 三关验证 | 每个引用来源经「可访问 / 内容匹配 / 来源标注」三重验证 |
| 交付物框架 | 内容目录树 + 单文件总报告 + 结构化数据底座（全字段带来源） |
| 质量铁律 | 数据真实（宁可 20 条填齐，不列 100 空壳）· URL 真实 · 证据优先 |

## 真实案例

**宠物食品行业 · 全域认知系统**（2026-08 蒸馏执行）

输入「宠物食品行业」→ 输出：
- 15 家品牌全景（麦富迪 / 皇家 / 渴望 / ZIWI / 高爷家 / 蓝氏 / 鲜朗 / 诚实一口 / 网易严选 / 京东京造 等，含层级与核心产品线）
- 7 家竞品 12 维拆解（定位 / 转化路径 / 信任机制 / 定价 / 内容策略 等）
- 17 条行业痛点（含致瘫恐慌、批次品控不透明等，全部带证据来源）
- 15 个机会点（批次质检追溯 / 宠物鲜食 / 宠物中医科普 / 营养品细分 等，带置信度）
- 20 个内容账号档案 + 50 个关键词库 + 8 条风险清单

> 完整方法论见 [METHOD.md](METHOD.md)，案例详情见 [CASE-STUDY.md](CASE-STUDY.md)。

## Quick Start

本项目为**纯静态演示**（零依赖，无后端）：

```bash
# 任选其一
python3 -m http.server 8000     # 本地起服务
# 或直接用浏览器打开 index.html
```

> 演示页中的「下载交付物」为流程示意（Key 验证逻辑为演示用），真实交付请联系获取。
